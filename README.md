# Four-Player Chess Game Simulation

This repository contains a four-player chess game simulation implemented in Java using object-oriented programming principles. The project aims to provide a solid foundation for multiplayer chess gameplay, with potential future extensions for AI-driven game engines, possibly incorporating machine learning.

Features

Four-player chess game mechanics

Object-oriented design for scalability
